# 当前方案与下一轮试点

## 当前版本

原工位的动作路径用 MediaPipe 人体与双手特征、25 帧 LSTM 和规则投票。当前离线接入把戴手套的手作为独立观测，R19 提供手框，当前帧完全漏手时调用 R29，R18 在手框内预测二维 21 点。R26 结合手部图像特征、局部几何与双 ROI RGB，上下文窗口为最近 32 个观测，感受野为 29 个观测，以 12.5 Hz 读取原生 25 fps 录像。

| 已检查的内容 | 结果与口径 |
| --- | --- |
| 旧六段已打开的开发录像 | 宏观作业 F1 从 0.889 到 0.935 |
| 连续三分钟的手部观测 | 从 2109/2250 到 2181/2250，覆盖约 93.7% → 96.9% |
| 同一三分钟的固定网格评分 | 宏观作业正点均检出 35/60，负点均误报 0/20 |
| 戴手套指尖的最新因果修正对照 | 同一批 49 个粗标可见指尖上，R18 NME 0.03676，相同图像特征加 16 帧历史后为 0.03755，越低越好。沿用 R18 |
| 累计时长规则 | 21 项状态机测试覆盖恰满 3 秒、短暂真断开、遮挡未知和时间戳异常。物理接入识别尚待现场数据验证 |

旧五分钟已确认过相邻两次实际接入。源录像约 193 秒处确有断开重接，R25 却输出连续约 35 秒的宏观动作。在这个工况下，给动作概率增加平滑会吞掉短断开。原方案保留为同段对照，接入状态从管端与工具口的局部证据学习。

## 逐根试拍

1. 一次拿起一根。操作员保留平常握姿和节拍。上一根从接口退出、放至已处理区后再取下一根。
2. 先录一段约五分钟的原始连续录像。镜头尽量同时包含接合处和操作区。现场记录接入、退出、重接的顺序，算法团队逐帧标注并复核短间隔。
3. 可见性确认后，按整条视频、捆次、操作者和日期分训练与留出。先比较固定手部与 R26 特征的基线，再加接口局部原图，最后比较是否增加接入与退出的边界监督。
4. 最终按源 PTS 对真实接入逐次记起止。实际连续满 3.000 秒才计一次，确认断开后重新计时，无法确认的时间段留待复核。

评估时报告真值接入的一对一匹配、相邻事件拆分、漏计和多计、每五分钟的绝对计数误差以及待复核比例。要核对整捆是否完成，需要能追清每根取出到放回的身份，或在工位使用可核对的唯一槽位。详细设计和建议试点门槛见 [现场方案 PDF](pilot-plan.pdf)。
